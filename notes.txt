Simple hello-world nginx from here: https://hub.docker.com/r/nginxdemos/hello/ that serves a simple page containing its hostname, ip address, and port, and the request URI and local time of the webserver.
docker pull nginxdemos/hello
docker run -P -d nginxdemos/hello

https://kind.sigs.k8s.io/docs/user/quick-start/#installation
We need to load the image into the cluster
kind load docker-image nginxdemos/hello  --name ${cluster_name}
# to see what images are loaded in a cluster control plane
docker exec -it ${cluster_name}-control-plane crictl images

# use the image we just pulled down
Kubectl create deployment kind-nginx --image=nginxdemos/hello

# for local images, can also do
Kubectl create deployment kind-nginx \ (or whatever name you chose
--image ${image_name} --dry-run -o yaml > ${manifest_file_name}.yaml
kubectl apply -f ${manifest_file_name} 
In there, you'll need to specify the container port and some image pull policy:

- image: part-1-backend:latest
  ports:
    containerPort: 8000
  name: part-1-backend
  resources: {}
  imagePullPolicy: Never # with this, you'll be able to see your pod running


We need to figure out which port is exposed in the nginx container:
docker image inspect nginxdemos/hello --format='{{.Config.ExposedPorts}}'

Then, when we create the service by exposing the deployment, we know which ports to use
kubectl expose deployments/kind-nginx --type="NodePort" --port=8080 --target-port=80

# enable port forward from outside the cluster to the service
kubectl port-forward service/kind-nginx 8000:8080

And then we can visit http://127.0.0.1:8000/

# https://medium.com/@tylerauerbeck/metallb-and-kind-loads-balanced-locally-1992d60111d8

kubectl apply -f https://raw.githubusercontent.com/metallb/metallb/v0.14.8/config/manifests/metallb-native.yaml
# tell kubectl to wait until some conditions on some resources are met
kubectl wait --namespace metallb-system \
  --for=condition=ready pod \
  --selector=app=metallb \
  --timeout=90s

# get the metalb pods
kubectl get pods -n metallb-system

# create the config from the IP pools
kubectl apply -f metallb-config.yaml
